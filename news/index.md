# Changelog

## brainwritR 0.1.0

- Initial classroom brainwriting application with German participant and
  moderator views.
- SQLite persistence, frozen sheet counts, balanced groups and late
  joining.
- Server-authoritative rounds, reconnect/resume and debounced draft
  saving.
- Server-side moderator authorization and transactional lifecycle
  operations.
- CSV and Markdown export, container deployment and classroom guide.
